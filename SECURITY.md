# Security Policy

## Supported Versions

Only the latest released version of `k8s-switch` is supported with security
fixes.

| Version | Supported          |
|---------|--------------------|
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, use GitHub's private vulnerability reporting for this repository:
open the [Security tab](https://github.com/tuplle/k8s-switch/security) and
select "Report a vulnerability". This creates a private advisory visible only
to the maintainers until a fix is available.

Please include as much detail as possible: the affected version, steps to
reproduce, and the potential impact. We'll acknowledge reports as soon as
possible and keep you updated as the issue is investigated and resolved.
